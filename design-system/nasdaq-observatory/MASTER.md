# 纳指观测设计规范

产品：面向中文用户的 ETF 数据对比与美国经济日历。优先保证数值、日期、来源与操作反馈清晰，保留现有品牌绿色。

## 依据与适配

使用 UI UX Pro Max：先运行 `financial analytics dashboard --design-system --variance 3 --motion 3 --density 7`，命中 Minimalism & Swiss Style 与数据字体建议，但其 Enterprise Gateway 营销布局不适用；随后用 `financial dashboard --domain product` 校正，命中 Financial Dashboard（主推荐 Data-Dense Dashboard，次推荐 Minimalism & Swiss Style / Accessible & Ethical）。最终采用金融看板结构，排除营销 hero、销售 CTA 和滚动展示动效。

查询来源：[UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)，本次读取提交 `d14efff8ed1faa4187f004f79926f428c8074ec7`。数据库输出为设计参考，以下为针对既有产品调整后的最终规则。

## 颜色与主题

颜色集中在 `src/styles.css`，组件只引用语义变量。

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 `--bg` | #f7f9f8 | #121d1a |
| 面板 `--panel` | #ffffff | #182620 |
| 主文本 `--ink` | #1b2b28 | #e5eee8 |
| 辅助文本 `--muted` | #52675e | #a6bbaf |
| 强调 `--accent` | #0b6b52 | #89d8b6 |
| 正溢价 `--up` | #a24a24 | #f0b087 |

正负溢价同时展示符号与数值，不只依赖颜色。日历类别同时带文字。图表使用四种主题感知的 `--series-*`，图例显示基金公司与代码。

## 排版与布局

- 系统字体：Segoe UI / Microsoft YaHei / system-ui，避免第三方字体请求和中文缺字。
- 数据：Cascadia Code / Consolas / Microsoft YaHei，使用 `tabular-nums`。
- 正文 14px；解释内容 12px；有限空间的辅助标注 10–11px；指标数值 25–34px。
- 间距基于 4px：4 / 8 / 12 / 16 / 24 / 32 / 48。控件圆角 6px，面板 12px。
- 桌面固定导航，内容最大宽度 1304px；平板压缩导航；手机采用品牌条和可见页面链接。
- 375 / 768 / 1024 / 1440px 验证；表格使用有标签、可聚焦的内部横向滚动区域，页面自身不横向溢出。
- 日历在窄屏上下排列；桌面详情高度跟随日历板，内容在面板内部滚动。

## 动画与反馈

- CSS 反馈：140ms；一般过渡：220ms。显式指定变化属性。
- Motion 分段指示器使用可中断 spring（stiffness 380 / damping 30）。
- VIX 指针保留 SVG 交互和弹簧回弹，清楚标记“交互预览”与“最新收盘”；支持方向键、Home / End / Escape。
- 统计卡片采用独立白色外壳和有色数值区，主基金区间均值突出显示。鼠标进入时浮起 5–8px、随指针轻微倾斜并移动光晕，离开后以 spring（stiffness 240 / damping 23）回正；静态外层接收鼠标事件，防止卡片边缘抖动。触摸和减少动态效果时不启用倾斜。
- 切换时间区间或增添基金时，SVG 曲线在 650ms 内绘制；数字只在真实值变化时短暂过渡，不伪造计数。图表游标、浮层、基金标签增删、表格排序、页面和日历切换统一使用短过渡。
- 页面省去宣传标题、英文装饰标签和重复操作提示，优先呈现操作、日期与数据。
- 全局遵守 `prefers-reduced-motion`，减少动态效果时直接显示最终状态。
- 请求中禁用刷新按钮并显示状态；失败保留已有数据，提供下一步操作。
- 桌面精细指针采用 iPadOS 风格的圆点跟随与磁吸底板：18px 圆点进入按钮时变成相应圆角矩形，按压收缩并回弹，无描边、无点击遮挡。基于开源 Motion 独立实现，未引入 Motion+ Cursor。输入、图表、VIX 拖动、键盘、滚动、触摸、强制颜色及减少动态效果均回退原生指针。
- “＋对比”和标签移除使用 Motion `arc()`；标签以 600ms 弧线进入 / 退出并让相邻项回弹，按钮图标以 450ms 弧线切换。退出标签禁用，避免重复触发。减少动态效果下立即切换真实状态。
- “接下来重点事件”栏桌面固定 184px，手机固定 310px；不足三条或无数据也保留栏高。长内容在事件内部滚动，完整信息仍可通过点击事件查看。

## 可访问性与数据约束

- 使用原生按钮、链接、表单、表格；图标来自 Lucide，装饰图标隐藏于辅助技术。
- 保留跳至主要内容链接、控件标签、选中状态与 live status。VIX、搜索、日期和时区控件取消外侧矩形焦点框：键盘导航使用细下划线或针色变化提示，普通按钮继续使用清晰焦点样式。
- 手机常用操作 44px 左右；日历采用紧凑控件，使用列表视图提供更宽的替代入口。
- 历史溢价使用同日净值；最新参考值与历史值分开标记，不补造历史记录。
- 保留时区换算、日期型事件、财报电话会和官方来源，不生成或改写金融事实。
